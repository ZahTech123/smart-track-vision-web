
# Smart Track - Vehicle Tracking Website Images

This folder contains the following images used by the Smart Track vehicle tracking website:

1. hero-cityscape.jpg - A background image showing a city skyline for the hero section
2. red-suv.png - An image of a red SUV vehicle for the hero section
3. mobile-app.png - A mobile app mockup showing a tracking interface
4. dashboard-mockup.png - A desktop dashboard mockup showing the tracking platform

Note: These are placeholder instructions. Actual images need to be placed in this public directory with these filenames for the website to display correctly.
