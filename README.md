# Smart Track PNG

Website for Smart Track PNG, providing vehicle tracking and fleet management solutions in Papua New Guinea.

## Local development

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The production output is generated in `dist/` and can be deployed to Vercel.

## Technology

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS
